## 📌 Project Overview

This repository contains an end-to-end data analytics project featuring an interactive **Microsoft Excel Dashboard** (`Mayur_ExcelDashboard.xlsx`) built upon the processed raw dataset (`train.csv`). 

The primary objective of this project is to analyze operational performance, uncover key trends, track core KPIs, and deliver actionable data-driven insights through dynamic data visualizations.

---

## 📁 Repository Structure

```text
.
├── Mayur_ExcelDashboard.xlsx   # Main interactive Excel dashboard & reports
├── train.csv                   # Source dataset used for processing & analysis
└── README.md                   # Project documentation & overview
```

### File Breakdown

* **`Mayur_ExcelDashboard.xlsx`**
  * Fully formatted interactive dashboard.
  * Pivot tables, aggregated KPIs, and visual charting.
  * Dynamic filtering using slicers and timelines.

* **`train.csv`**
  * Raw observational dataset used to drive the analysis.
  * Formatted for seamless ingestion into Excel, Python (Pandas), or SQL environments.

---

## 🔑 Key Dashboard Features

* **Interactive Slicers & Filters:** Filter dynamic charts across various dimensions with zero formula breakage.
* **KPI Metrics Summary:** High-level summary of critical business performance numbers.
* **Trend & Pattern Analysis:** Visual breakdown highlighting seasonality, distribution, and performance anomalies.
* **Automated Data Aggregation:** Structured Pivot Tables and calculated fields to convert raw data into business intelligence.

## 🚀 Getting Started

Follow these steps to set up and explore the dashboard locally:

### Prerequisites

* Microsoft Excel (2016 or newer recommended) or Microsoft 365.
* Git (optional, for cloning the repository).

### Step-by-Step Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```

2. **Access the Dataset:**
   * Inspect `train.csv` in Excel, VS Code, or Python to explore the foundational data schema.

3. **Launch the Interactive Dashboard:**
   * Open `Mayur_ExcelDashboard.xlsx` in **Microsoft Excel**.
   * If prompted, **Enable Content / Macros** to ensure all dynamic interactive controls function smoothly.
